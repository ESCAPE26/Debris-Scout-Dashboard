# Debris Scout AI — Web Dashboard Prototype

A bespoke, browser-based mission-control dashboard that demonstrates the **Detect → Track → Predict → Assess Risk → Plan/Avoid** pipeline for the [Debris Scout](https://github.com/SSN2025/SSN2025-ISRO-Hackathon-Debris-Detection-) concept: a distributed network of co-orbital sentinels that sense their local environment and protect a high-value spacecraft from debris.

This package is the **visualization + simulated-pipeline layer** requested on top of that project, completely redesigned with a deep-ocean/aerospace aesthetic. It runs entirely in the browser — no build step, no backend, no GPU, no real sensor hardware required.

## What this is / is not

| This prototype **is** | This prototype **is not** |
|---|---|
| A software simulation of detection, tracking, prediction and collision-risk assessment | Connected to a real camera, radar, or orbital catalog |
| A highly polished research / academic demonstration product | Flight-qualified or ISRO-certified software |
| Built on a simplified, honestly-scoped relative-motion model | A validated SGP4 / full numerical-propagator implementation |
| A visual narrative tool for explaining *how* the pipeline works | A statistically calibrated collision-probability product |

Every metric on the screen (positions, confidence, risk score, Δv) is generated by the in-browser simulator. The **AI MODE: SIMULATION** badge is permanently affixed to the header to preserve technical honesty.

## How to run it

1. Ensure all files (`index.html`, `style.css`, `app.js`, `404.html`) are in the same folder.
2. Open `index.html` in any modern desktop browser (Chrome, Edge, Firefox).
3. Click **Start Sim**, or pick a scenario from the dropdown.
4. Click a row in the **Mission Tracks** table to inspect an object, view its predicted trajectory graph, and (if its risk is elevated) run **Simulate Clearance Maneuver**.
5. Try **DEMO MODE** in the scenario dropdown for an automated, scripted end-to-end walkthrough.

No install, no backend required. It runs purely client-side.

## Pipeline Architecture in `app.js`

The codebase is logically separated to map to the assignment brief's stages:

- **Sense / Detect**: Simulated camera/radar measurement with probabilistic false contacts and noise injection.
- **Track**: Alpha-filter fusion approximating the C++ repo's UKF, building persistent object states from noisy observations.
- **Predict**: A physics baseline (linear in-plane motion + exact closed-form cross-track harmonic solution) combined with a deterministic `mlResidual()` function simulating learned network corrections.
- **Assess Risk**: Calculates closest-approach geometry to generate a prototype risk score (0-100) and actionable category (GREEN/YELLOW/ORANGE/RED).
- **Protect**: Avoidance simulator suggesting radial Δv for clearance.

## Technical Honesty & Limitations

- **Relative-Motion Physics**: In-plane motion uses a first-order linearized approximation suitable for the <5-minute windows displayed. It is explicitly labeled a "Simplified Relative-Motion Model" rather than a full validated propagator. 
- **AI/ML Layer**: The dashed ML residual line is an illustrative deterministic function (`mlResidual()`), designed to make the *concept* of physics + AI residuals tangible for judges. It is not a trained neural network.
- **Risk Score**: It is labeled "Prototype Risk Score" because it uses heuristic distance scaling rather than a formal Foster-1992 B-plane collision probability integral.
